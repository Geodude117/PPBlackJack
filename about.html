About Perfect Pair Blackjack

Perfect Pair Blackjack is a free, play-money blackjack game with the Perfect Pairs and 21+3 side bets, built and maintained by one developer.

The story

The game started life as a university project, written in C# with the Unity game engine. I later rebuilt it from scratch as a native iPhone app in SwiftUI, adding drag-and-drop chip betting, the Lucky Pair jackpot and basic strategy hints.

In October 2026 I brought it to the web, so anyone can play in a browser on any phone, tablet or computer, with nothing to install. The web version was ported from the Swift code with the help of Claude, an AI assistant, and tested by playing hundreds of automated rounds to check every payout.

What’s here

  • The game: six-deck blackjack with Perfect Pairs, 21+3, insurance, splits, doubles and optional strategy hints.
  • Guides: how to play, the basic strategy chart, Perfect Pairs, 21+3, insurance and side bets compared.
  • Odds calculator: exact side bet odds for any number of decks.
  • What’s new: every update to the game and site, with dates.

All the odds on this site are calculated exactly, by counting every possible card combination, rather than copied from elsewhere.

Play money only

Perfect Pair Blackjack is a game for fun and practice. Chips have no cash value, there is no real-money gambling, there are no prizes and there is nothing to buy. If you run out of chips you can top up for free.
